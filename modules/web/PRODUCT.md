# Papita (`save-ma-money` Web SPA)

Personal and household financial ledger, cashflow reporting, payment dues, projections, and email-ingested transaction management.

- **Mode:** Operate (precision, scanability, tabular numeric clarity, restrained craft)
- **Brand Personality:** Calm, auditable, trustworthy, crisp, utilitarian
- **Architecture:** Presentation-only React + Vite + TanStack Query SPA backed by `papita_txnsapi` (`/api/v1/*`)
